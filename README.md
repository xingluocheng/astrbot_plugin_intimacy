# 大肥鱼的亲密度 · astrbot_plugin_intimacy

> 按聊天天数推进关系：生人 → 眼熟 → 亲密，主人恒定最高 · AstrBot 插件

---

## 一、这是什么

让她记得「和这个人聊了多久」，并据此调整说话的距离。

插件按人记录三件事：第一次见面是哪天、实际聊过几个不同的日子、一共说了多少条。聊的天数越多，熟悉度越高，她对这个人的态度就越放松——从客气，到会开玩笑，再到会主动找人说话。

熟悉度会以一小段提示注入到她的上下文里，所以她知道对面是谁、熟到什么程度：不会对陌生人撒娇，也不会对老朋友见外。

---

## 二、功能

| 功能 | 说明 |
|---|---|
| 四个档位 | 生人 / 眼熟 / 亲密 / **主人（恒定最高）** |
| 按天推进 | 算「实际聊过几个不同的日子」，不是自然日跨度 |
| 上下文注入 | 每轮对话告诉她「这是谁、认识多久、什么档位」 |
| 主人豁免 | `owner_ids` 里的人恒定最高档，不随天数变化 |
| 只记私聊 | 默认不统计群聊，避免群里刷条数 |
| 纯 json 存储 | 数据可以直接看、直接改，删掉某号就是「重新认识」 |
| 日记联动 | 日记插件会读这里的记录，把亲密的人写进日记 |

## 四、⚠️ 怎么改成你自己的 QQ 号

**这是装完必须做的第一步，不做的话「主人恒定最高」不生效。**

### 两个号要分清

| 号 | 是什么 | 在哪改 |
|---|---|---|
| **大肥鱼（机器人）的 QQ** | 机器人登录的那个号 | 配置项 `bot_ids`。留空 = 自动排除当前登录账号；填了按这个号排除，不会把机器人自己算成聊天对象 |
| **主人的 QQ** | 你的个人号，这个号恒定最高档 | 插件的 `owner_ids` 配置 |

### 改法 A：在面板里改（推荐）

面板 → 插件 → 大肥鱼的亲密度 → **配置** → 找到 `owner_ids`：

```
3640280199      ← 把它改成你自己的 QQ 号
```

多个用英文逗号分隔：`123456789,987654321`

### 改法 B：直接改配置文件

```
AstrBot/data/config/astrbot_plugin_intimacy_config.json
```

```json
{
  "owner_ids": "你的QQ号"
}
```

### 不改会怎样

`owner_ids` 留空 → 退回 AstrBot 管理员判定 → `admins_id` 默认是 `["astrbot"]`，不是 QQ 号，**永远匹配不上**。结果：你的号会被当成「生人」，要说很多天才升级，而不是恒定最高。

## 五、使用方法

装完不需要做任何事，她说话会自动分亲疏。

### 四个档位

| 档位 | 条件 | 她怎么说话 |
|---|---|---|
| 生人 | 没聊几天 | 礼貌有距离，称呼哥哥/姐姐 |
| 眼熟 | 聊满 `familiar_days`（默认 3 天） | 会开玩笑、会吐槽、记得上次说的事 |
| 亲密 | 聊满 `close_days`（默认 14 天） | 会主动找人、会说心事、会留意状态 |
| **主人** | `owner_ids` 里的人 | **恒定最高，不随天数变化** |

「天数」= 实际聊过几个**不同的日子**。隔一天没聊不算，同一天聊一百条也只算一天。

### 注入的内容

对别人：

```
【熟悉度】你正在和「小晴」聊天（不是主人）。
认识 12 天，实际聊过 8 天，共 214 条。当前熟悉度：亲密。
按人设「关系与距离」那节调整距离，别越界，也别叫主人。
```

对主人只有一句：

```
【熟悉度】对方是主人。亲密度：最高（永远，不随天数变化）。
```

### 指令

| 指令 | 作用 |
|---|---|
| `/亲密度` | **主人发**：列出所有人（昵称 / 档位 / 聊过几天 / 共几条 / 还差几天升级）　**其他人发**：只看自己那条 |
| `/好感度` | 旧指令，保留兼容，等同 `/亲密度` |

## 六、配置项

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 总开关 |
| `owner_ids` | **空** | **必填**，主人 QQ 号 |
| `bot_ids` | **空** | 大肥鱼的 QQ；留空自动排除机器人自己 |
| `familiar_days` | 3 | 眼熟门槛 |
| `close_days` | 14 | 亲密门槛 |
| `scope` | **all** | `private` 只私聊 / `group` 只群聊 / `all` 私聊+群聊都算（默认） |
| `inject_enabled` | 开 | 是否注入上下文 |
| `show_count` | 开 | 注入时带不带消息条数（关掉省 token） |

## 七、数据存在哪

```
AstrBot/data/plugin_data/astrbot_plugin_intimacy/users.json
```

```json
{
  "3640280199": {
    "first": "2026-10-20",
    "last": "2026-10-31",
    "days": ["2026-10-20", "2026-10-25", "2026-10-31"],
    "count": 214,
    "name": "主人"
  }
}
```

- `first` 第一次说话是哪天
- `days` 实际聊过天的日子列表（最多保留 400 天）
- `count` 总条数
- 删掉某个号 = 让它「重新认识」

## 八、和「大肥鱼的日记」联动

两个插件是上下游：

```
本插件   → 按聊天天数判断谁够亲密 → 写进 users.json
                                    ↓ 读取
日记插件 → 够亲密的人也能进日记
```

| 装了什么 | 效果 |
|---|---|
| 只装本插件 | 她说话会分亲疏，但日记里只有主人 |
| 只装日记 | 日记里只有主人 |
| 两个都装 | 日记里会出现「小晴」这样的亲密朋友，称呼自动区分 |

⚠️ 门槛要对齐：本插件的 `close_days` 要等于日记插件的 `intimate_days`（默认都是 14）。

本插件是**上游**，只负责产出 `users.json`，不读别人的数据——所以单独装也不会报错，只是日记那边拿不到人。
